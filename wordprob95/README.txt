WORDPROB95.EXE — Windows 95 themed multi-step word problems for grade 3

1. Open index.html in Chrome to test it locally.
2. Create a public GitHub repository named wordprob95.
3. Upload index.html into the repository root.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Wait for deployment, then open https://YOUR-USERNAME.github.io/wordprob95/
6. In Classroomscreen's Embed widget, try:
<iframe src="https://YOUR-USERNAME.github.io/wordprob95/" width="600" height="600" style="border:0" title="Multi-step word problems"></iframe>

If the page shows a frowny face in Classroomscreen, first verify it opens in a normal browser. The hosting platform alone cannot guarantee iframe compatibility. Use a hyperlink widget to open it in a separate tab if necessary.

Daily question selection uses the local date; the Next button cycles through the selected level. 16 included problems. No tracking, accounts, external libraries, or API calls.
